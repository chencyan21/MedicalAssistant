# Idea 4：FreqReward — 频域保真约束 + VLM 奖励模型的编辑模型 RL 后训练

> 一句话：训练一个融合"语义对齐（VLM 打分）+ 频域保真（非编辑区频谱一致性）"的复合奖励模型，用 GRPO/flow-RL 对开源编辑模型（Qwen-Image-Edit / Step1X-Edit）做后训练，系统性修复"编辑过度修改"这一 reward hacking 与保真度失衡问题。

---

## 1. 研究动机与问题定义

**背景**（综述 §2.2(3)）：VLM 奖励模型驱动编辑后训练已被验证有效——EditReward（ICLR'26）用 Qwen2.5-VL 多维排序做数据筛选；EditHF-1M（2603.14916）用百万级人类偏好 + RL 微调 Qwen-Image-Edit 获显著提升。

**现存问题**：
1. **语义偏向与 reward hacking**：VLM/CLIP 系奖励本质衡量"语义是否改成目标"，对"不该改的地方变没变"不敏感。RL 优化下模型学会"整图重画但语义沾边"来骗分——非编辑区保真度随训练步数**持续恶化**（EditHF 论文中已可见此倾向）。
2. **保真度度量缺失**：现有 reward 无一显式度量非编辑区的结构/纹理保真。频域恰好提供最自然的工具：非编辑区的相位谱（结构）与分带能量（纹理）一致性，是 CLIP 类语义指标捕捉不到的物理量。
3. **少步蒸馏的高频丢失**：schnell/Turbo 类 4 步模型的编辑结果高频纹理明显退化，蒸馏目标中没有频域约束（综述 §4.5）。

**问题定义**：设计复合奖励 R = R_vlm（语义对齐）+ λ·R_freq（非编辑区频域保真）+ μ·R_aes（美学），用 GRPO 对 flow-matching 编辑模型后训练，在保持编辑成功率的同时把非编辑区保真度拉回。

**为什么值得做**：① RL-for-editing 是 2026 年明确热点（EditReward、EditHF、RetouchIQ 三连发），但**频域保真奖励无人提出**；② 工程管线（GRPO for flow matching）已有开源基础（diffusers/TRL 系），复现门槛低；③ 奖励模型本身可独立发表为评估工具（衔接综述 §3.4 的评估空白 G6）。

---

## 2. 相关工作与差异化

| 工作 | 关系 |
|---|---|
| EditReward (ICLR'26) | VLM reward 基座；本文在其输出上加频域保真头 |
| EditHF-1M (2603.14916) | 人类偏好数据 + RL 管线；可直接复用其数据与训练框架 |

**差异化**：首个把**频域物理保真**引入编辑奖励模型；瞄准"reward hacking 导致保真度崩坏"这一真实且可量化的问题。

## 3. 方法设计

### 3.1 频域保真奖励 R_freq

给定原图 I、编辑结果 Î、编辑掩码 M（由编辑数据标注或 SAM 自动生成）：

- **结构项**：非编辑区相位谱余弦相似度 s_φ = cos(∠FFT(I)⊙(1−M), ∠FFT(Î)⊙(1−M))；
- **纹理项**：非编辑区 DWT 各子带能量的 L1 一致性 s_w = 1 − Σ_b ||E_b(I) − E_b(Î)||₁（b ∈ {LL,LH,HL,HH}，能量在 (1−M) 区域统计）；
- **编辑区自由度**：编辑区内不约束（允许任意改变），但对其高频能量做正则防止噪点伪影；
- R_freq = w₁·s_φ + w₂·s_w。全部可微，也可作训练 loss 使用（两个用途：reward 项 or 直接正则项，论文中对比）。

### 3.2 复合奖励模型训练

- 基座：Qwen2.5-VL-7B，按 EditReward 协议在人类偏好数据（EditHF-1M 子集 + 自建"语义对但保真差"难例对）上训练排序头；
- 难例对构造（关键巧思）：用现有强编辑模型生成结果后，**人为扰动非编辑区**（轻度频移/重渲染）制造"语义相同、保真不同"的成对样本——纯 VLM reward 无法区分，复合 reward 可以，这是证明 R_freq 必要性的直接证据；
- R = R_vlm + λ·R_freq（λ 经校准集网格搜索，目标 0.3–0.5）。

### 3.3 RL 后训练

- 基座模型：**Qwen-Image-Edit**（Apache 2.0，许可干净，且 EditHF 已证明其可 RL 提升）；
- 算法：GRPO（每 prompt 采 8–16 个样本，组内相对优势），冻结 VAE 与文本编码器，LoRA 或全参（视算力）；
- 对照组：① 无 RL；② 仅 R_vlm 的 RL（复现 EditHF 式结果，预期保真度退化）；③ R_vlm + R_freq（本文）；④ R_freq 作为直接 loss 的 SFT 变体。

### 3.4 副产品：频域感知的开源评估器

将训练好的复合 reward 以"编辑评估器"形式开源，提供语义+保真双维分数——回应综述 G6（评估体系空白），增加论文被引面。

## 4. 实验方案

**主实验**：Qwen-Image-Edit + GRPO，在 GEdit-Bench / KontextBench（内部评测）/ MagicBrush 上评测。

**指标**：
- 语义对齐：CLIP-T、VIEScore、EditReward、GPT-4o 打分；
- **保真度（主打）**：非编辑区 PSNR/LPIPS/DINOv2 + 本文的 s_φ/s_w；
- 整体：人工偏好（三模型锦标赛：原模型 / RL-vlm / RL-vlm+freq）。

**关键实验（论文图 1 候选）**：RL 训练曲线上"语义分 ↑ 但非编辑区 LPIPS ↑（变差）"的背离现象（仅 R_vlm 组），对比本文组双指标同步改善——reward hacking 的实证是故事核心。

**消融**：① λ 敏感性；② 相位项/小波项各自贡献；③ reward 项 vs 直接 loss；④ LoRA vs 全参；⑤ 难例对构造的必要性（去掉后复合 reward 退化为普通 reward）。

**延伸验证（可选）**：对 FLUX.1-schnell 做 4 步编辑蒸馏，加频域 loss 防止高频丢失（综述 §4.5 方向 4），作为论文的应用展示。

## 5. 可行性与风险

**可行性**：RL 训练 20B 模型需多卡（8×A800 级，LoRA 可降至 4 卡）——这是四个 idea 中算力需求最高的；若资源有限，可降级到 FLUX.1-schnell 12B LoRA 或 SD2.x 上的 InstructPix2Pix 复现 + RL（单卡可行，作为方法学验证）。预计 3–4 个月。

**风险与对策**：
1. **算力不足** → 降级路径明确（SD2.x + InstructPix2Pix + GRPO，故事不变、规模变小）；或只做 reward 模型 + best-of-N 筛选（免 RL，仍能证明 R_freq 价值，ICEdit 已验证 best-of-N 路线有效）。
2. **R_freq 与 R_vlm 冲突导致训练不稳** → λ 退火（早期重语义、晚期重保真）；或约束式 RL（保真度低于阈值则拒绝更新）。
3. **掩码 M 依赖标注质量** → 用 SAM 自动生成 + 消融无掩码变体（全图相位统计的弱化版）。
4. **与 EditHF-1M 撞车风险**（其团队可能已加保真项）→ 投稿前复查其最新版本；差异化点押在频域物理量与难例对构造。
5. **频域指标与人感知不一致** → 人工评测必须覆盖"非编辑区是否变了"这一独立维度，验证 s_φ/s_w 与人判断的相关性（相关性本身也是论文贡献）。

**目标会议**：NeurIPS 2027 / ICLR 2027；reward 模型部分可先发 workshop 或单独短文。
