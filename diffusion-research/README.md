## 核心结论速览（第三轮终审版，以 07 号文档为准）

1. **双主攻旗舰**：D（风格代数：FLUX 调制空间的正交风格因子 + 推理时风格算术，上限 9.0）+ A（速度场频域解剖修正版：可辨识窗口 + **反转的灵敏度定律**——低频扰动远比高频危险，∩形曲线峰值 t_c=S/(1+S)，上限 8.0）。
2. **戏剧性纠错**：独立数学审查发现原理论传播因子是正确灵敏度的倒数，三个预测全部反转——修正后反而推翻社区"高频脆弱"直觉（含 FreqFlow CVPR'26 隐含假设），成为可证伪的 headline。
3. **组合策略**：C（元素级风格评估，空白 80%、致死率 42% 最低）被 F（UDTCWT 平移鲁棒度量、结构化噪声、平滑窗算子）武装为对冲资产；B（频谱 VLM+编译增益场，上限 9.5 但致死率 80%）冻结为 2 周探针；E 枪毙。
4. **本月关键路径**：① D 正交性判决实验（1–2 周，go/no-go 闸门）；② A 的非高斯修正定理成稿；③ B 两个探针。
5. **投稿时间线**：AAAI 2027 放弃（已过）；CVPR 2027（约 2026-11 截稿）A、D 双投；C 先上 arXiv 供引用。

1. **Backbone 选型**：方法学研究/经典基线对比 → SD1.5 优于 SD2.x；面向 SOTA → FLUX.1-dev（学术）+ Qwen-Image-Edit/schnell（Apache 2.0）。
