# Idea 3：GroundFreq — VLM 语义定位 × 频域强度调制的精确指令编辑

> 一句话：让 VLM 输出"编辑什么、在哪里、改多深"（指令解析 + 掩码 + 编辑深度类别），再用频域调度把编辑强度精确注入对应的"时间步 × 频段 × 空间区域"，解决指令编辑中"该改的没改透、不该改的全变了"的核心痛点。

---

## 1. 研究动机与问题定义

**指令编辑的两个核心痛点**（综述 §2）：
1. **定位不精确**：编辑泄漏到非编辑区域（全局漂移）。CAMILA（NeurIPS'25）、FireEdit（CVPR'25）用 VLM 生成 region tokens/mask 调制 cross-attention，显著改善但仍是"全频带、全时段"的粗粒度调制。
2. **强度不可控**：语义大改（换物体）与纹理小改（换材质）用同一套注入强度——前者需要早期低频干预（结构级），后者只需晚期高频干预（纹理级）。目前没有方法把"编辑类型的语义深度"与"采样的时间-频率结构"对齐。

**关键观察的交汇**：
- Fourier Space Perspective（2505.11278）：扩散逆过程"先低频结构、后高频细节"；
- FireEdit 的 Time-Aware Target Injection 已朴素验证"按去噪阶段调强度有效"，但其调度是手工的、无频域维度；
- FreSca 证明 CFG 差分项可安全做频域操纵；
- CAMILA 证明 VLM→mask→注意力调制的管线可行。

**空白**：VLM 语义理解（编辑类型识别）与频域编辑调度从未被连接。**"编辑类型的语义深度 ↔ 干预的时间-频段位置"这一对齐是本 idea 的核心创新。**

**问题定义**：给定图像 I、自由文本指令，模型自动完成：① VLM 解析指令得（目标区域掩码 M，编辑深度类别 d ∈ {纹理/属性, 物体/部件, 结构/布局}）；② 按 d 查表得到干预的时间步窗口 [t₁,t₂] 与频段集合 Ω；③ 在窗口内对 M 区域、Ω 频段做编辑引导，其余一律冻结。

**例子**："把猫的毛换成紫色"→ d=纹理 → 只在晚期高频干预；"把猫换成狗"→ d=物体 → 中期全频干预；"把猫移到画面左边"→ d=结构 → 早期低频干预。

## 2. 相关工作与差异化

| 工作 | 关系 |
|---|---|
| CAMILA (2509.19731) | VLM→mask→注意力调制管线；本文增加编辑深度分类与频域调度 |
| FireEdit (2503.19839) | region tokens + 时间感知注入；本文将其手工调度升级为语义驱动的频域调度 |
| SmartFreeEdit (2504.12704) / FoRE | MLLM+SAM 定位管线，作为定位模块的备选实现 |
| FreSca (2504.02154) | 频域操纵工具；本文用 VLM 决定"何时何地操纵哪个频段" |
| InsightEdit (2411.04423) | CoT 编辑规划；本文的深度分类可视为轻量版 CoT |
| Step1X-Edit (2504.17761) | VLM 条件注入的完整系统，作为端到端 baseline |

**差异化**：首次把"编辑语义深度"显式建模为可分类变量并与采样的时间-频率结构对齐；VLM 从"定位器"升级为"编辑规划器"。

## 3. 方法设计

### 3.1 模块一：VLM 编辑规划器

以 Qwen2.5-VL（7B，Apache 2.0）为底座，构造三输出头：
1. **掩码输出**：沿用 CAMILA 的 [MASK] token + Token Decoder → 二值掩码 M（或直接调用 SAM，用 VLM 输出点/框提示）；
2. **编辑深度分类**：d ∈ {texture, object, structure} 三分类（可扩展为连续值 d∈[0,1]）；
3. **指令重写**：输出扩散模型友好的精确编辑 prompt（MGIE 式）。

**数据**：从 UltraEdit/HQ-Edit/Emu Edit 数据中抽样，用 GPT-4o 标注编辑深度类别（"该编辑改变了图像的结构/物体/仅纹理属性？"），约 3–5 万条即可 LoRA 微调。

### 3.2 模块二：深度-时间-频率对齐表

核心设计（可学习或手工初始化后校准）：

| 深度 d | 时间步窗口 | 频段 Ω | 依据 |
|---|---|---|---|
| 纹理/属性 | t ∈ [0, 0.4]（晚期） | 高频 LH/HL/HH | 细节在晚期高频生成 |
| 物体/部件 | t ∈ [0.2, 0.7] | 全频 | 物体形成于中段 |
| 结构/布局 | t ∈ [0.6, 1.0]（早期） | 低频 LL | 结构在早期低频确定 |

（rectified-flow 约定 t=1 为纯噪声。窗口边界作为超参，通过校准集上的网格搜索微调。）

### 3.3 模块三：频域-空间联合编辑注入

在 backbone（FLUX.1-dev 或 SD2.x）采样中，每步 t：
- 若 t 不在 d 对应窗口内：对 M 区域不做任何引导，且用原始轨迹值替换（严格保护非编辑时空）；
- 若在窗口内：计算编辑引导项 Δv = v_θ(z_t | 编辑prompt) − v_θ(z_t | 原图prompt)，对其做 DWT，仅保留 Ω 频段，在空间上乘软掩码 M，加回速度场：v ← v + λ·DWT⁻¹(Ω ⊙ DWT(Δv)) ⊙ M。

### 3.4 训练与推理成本

VLM 侧 LoRA 微调（单卡可训）；扩散 backbone 完全冻结、免训练。系统可纯推理部署，也可进一步用 EditReward 做 best-of-N 筛选（衔接 Idea 4）。

## 4. 实验方案

**Backbone**：FLUX.1-dev（主）；**SD2.1**（作为 U-Net 对照组——本 idea 的频域调制在 U-Net latent 上机理已被 FreeU 验证，可检验方法跨架构普适性，且算力友好便于大规模消融）。

**Benchmark**：MagicBrush、GEdit-Bench、KontextBench（非商业许可注意仅作内部评测）、PIE-Bench。

**Baselines**：InstructPix2Pix（SD2.x 组）、CAMILA、FireEdit、SmartFreeEdit、Step1X-Edit、ICEdit。

**指标**：
- 编辑成功：CLIP 图文相似度（编辑区）、VIEScore、EditReward 分；
- 非编辑区保护：PSNR/LPIPS/DINOv2（非编辑区）——本方法的主打指标；
- 深度分类准确率：VLM 模块的独立评估（3 分类，目标 >85%）；
- 人工评测：按"编辑透/不伤周边"两维打分。

**消融**：① 频域调制开/关（仅 VLM+mask，退化为 CAMILA 式）；② 深度分类 vs 固定全时段全频；③ 对齐表窗口的敏感性；④ 软掩码 vs 硬掩码；⑤ VLM 定位 vs GroundingDINO+SAM 外挂。

**预期结果**：非编辑区保护指标显著优于全部 baseline（这是频域窗口 + 严格冻结的直接收益）；编辑成功率持平或优于 FireEdit；纹理类编辑（最常见需求）提升最大。

---

## 5. 可行性与风险

**可行性**：VLM LoRA（3–5 万数据）+ 扩散免训练，双卡即可完成全部实验；各模块（CAMILA 式掩码、FreSca 式频域操纵）均有开源实现可拼。预计 3 个月出主结果。

**风险与对策**：
1. **编辑深度三分类太粗，边界 case 多**（如"换背景"介于物体与结构之间）→ 改为连续深度值 d∈[0,1] 插值窗口；或用 VLM 直接回归窗口参数。
2. **严格冻结非编辑区导致编辑边界生硬** → 软掩码 + 边界频段过渡（掩码边缘只通高频）。
3. **VLM 掩码错误级联到编辑失败** → 置信度低时回退为全图编辑 + 弱频域约束；掩码质量纳入消融。
4. **创新点被拆解质疑（"CAMILA+FreSca 拼接"）** → 核心 claim 放在"语义深度↔时间-频率对齐"这一新概念及其系统性验证（对齐表的消融是论文灵魂）；提供理论叙述连接 2505.11278。
5. **端到端模型（Kontext/Qwen-Image-Edit）效果碾压** → 定位差异：本文是**可解释、可控、可组合**的轻量方案，可作为任意 backbone 的插件；并展示其在 SD2.x 这种小模型上赋予精确编辑能力的独特价值（低成本场景）。

**目标会议**：CVPR/ICCV 2027 或 ACM MM 2027。
