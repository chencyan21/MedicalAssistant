# 方案 A（主推）：速度场的频域解剖 —— Flow-Matching 编辑的频域理论

**题目方向**：*The Spectral Anatomy of Velocity Fields: A Frequency-Domain Theory of Flow-Matching Editing*

**一句话**：从 rectified flow 的线性插值结构出发，建立"速度场频谱随时间演化"的理论，由理论导出（而非手工设计）频域编辑算子与调度，实现免训练、可证明有界扰动的 FLUX 风格化与精确编辑。

## A.1 为什么这是顶会级

| 原 idea 的致命伤 | 本方案的解法 |
|---|---|
| "FreSca 多带软化 + ϕ-PD 相位 + 掩码"的组合式增量 | 频域算子成为**理论的推论**而非启发式拼盘；理论预测可证伪（预测 vs 实证频谱演化吻合图是审稿人无法拒绝的图） |
| "速度场频谱≠图像频谱"无依据 | 理论部分直接刻画 v(z_t,t) 的频谱结构——这正是该映射合法性的证明 |
| 调度是手工超参 | ρ(t)/η(t) 由**扰动有界性命题**导出（误差预算驱动的自适应调度） |
| 撞车 ϕ-PD / Wavelet Phase Diffusion | 差异化锚点：它们是噪声/样本域的**经验设计**，本文是速度场域的**原理框架**；且提供它们不具备的扰动上界保证 |

CVPR 近年对 "understanding + method" 双贡献论文（FreeFlux 的分析部分即被单独高度评价）接受度显著高于纯方法拼盘。

## A.2 理论部分（核心贡献 1）

1. **命题 1（频谱分层收敛）**：RF 前向 z_t = (1−t)x₀ + tε 中，设数据功率谱 S(ω)∝|ω|^(-β)，则速度场真解 v*(z_t,t) 的频率 ω 分量在 t 轴上的"可辨识窗口"与信噪比 SNR(ω,t) 单调相关——低频先收敛、高频后收敛。与 DDPM 的本质差异：DDPM 由噪声调度驱动，RF 由传输路径驱动（直线插值使该分层更"硬"）。
2. **命题 2（扰动有界性）**：在时刻 t 对 v_θ 施加频段 Ω 内、幅度 ≤ δ 的扰动，终端图像扰动 ||Δx₀|| 有界于 C(t,Ω)·δ，其中 C 随 t 增大（越早扰动影响越大）、随 Ω 频率升高而减小——**为"早期低频=结构级编辑、晚期高频=纹理级编辑"提供数学形式**，并给出安全扰动预算 δ(t,Ω)。
3. **推论（调度定理）**：给定编辑语义深度 d（连续标量，可由 VLM 输出或用户指定），最优干预窗口与频段由命题 2 的 C(t,Ω) 反解——**原 Idea 3 的手工对齐表被替换为公式**。

> 理论可行性：RF 的线性结构比 DDPM 更易分析（ODE 扰动分析 + Gronwall 不等式是成熟工具）；已有文献（Fourier Space Perspective, 2505.11278）完成了 DDPM 侧的对应分析，RF 侧是空白且可借力。若完整证明困难，可降级为"受控合成数据上的命题验证 + 一般情形的启发式论证"。

## A.3 方法部分（核心贡献 2，由理论导出）

- **SpectralFlow 算子**：在 Euler/Heun 采样的每步，对 v_θ 分解（DWT 或平滑 FFT 窗），按命题 2 的预算 δ(t,Ω) 施加：低频分量向内容反演轨迹投影（结构保持）、高频分量向风格方向对齐（风格注入）——形式上是带安全约束的投影算子，而非 ϕ-PD 式噪声改造；
- **连续深度接口**：d∈[0,1] 连续标量（纹理 0 ↔ 结构 1）→ 公式给出 (t 窗口, Ω 频段, δ 预算)，VLM 可选提供 d 的自动估计（吸收 Idea 3，但 VLM 只是"语义标量提供者"，调度由理论给出）；
- **空间局部化**：软掩码 M 与频带选择联合（软掩码经同一理论分析边界泄漏，给出掩码平滑度与频带截断的相容条件——回应 Wavelet Phase Diffusion 指出的 ringing 问题）。

## A.4 实验方案

1. **理论验证（论文图 1 候选）**：FLUX.1-dev 上实测 v_θ 频谱随 t 演化 vs 命题 1 预测；扰动传播实验 vs 命题 2 上界——吻合度曲线；
2. **风格化编辑**：StyleBench + KontextBench 风格子集；对比 StyleID、FreSca（FLUX 移植）、ϕ-PD、Wavelet Phase Diffusion、FireFlow、FLUX Redux；
3. **精确指令编辑**：MagicBrush/PIE-Bench；对比 FireEdit、CAMILA、Stable Flow、FreeFlux；
4. **消融**：理论导出调度 vs 手工调度（原 Idea 2 的 ρ(t)/η(t)）；DWT vs FFT 窗；有/无扰动预算约束（验证无约束时的伪影）；
5. **指标**：CSD+、ArtFID、DINOv2/LPIPS、非编辑区 PSNR + 人工偏好。

## A.5 风险与对策

| 风险 | 对策 |
|---|---|
| 理论证明做不出来 | 降级为"受控验证 + 启发式"，仍比纯启发式强一档；或与数学背景合作者合作 |
| FLUX latent 频谱语义混乱（命题 1 实证失败） | 预备实验先行（1–2 周）；若 latent 不成立，改在 ẑ₀ 预测空间做频域分析（每 k 步一次） |
| ϕ-PD / Wavelet Phase Diffusion 继续挤压 | 全程正面差异化：它们是经验设计，本文提供原理与保证；且作为 baseline 对比 |
| 时间窗口 | 该方向 2026 年快速升温，**建议 3 个月内完成投稿**（赶 AAAI 2027 / CVPR 2027） |

# 方案 B：EditDepth —— 编辑深度与频带失败模式的诊断 Benchmark

**题目方向**：*EditDepth: Diagnosing Depth-Aware Fidelity Failures in Instruction-Based Image Editing*

**一句话**：构造按"编辑深度（纹理/物体/结构）× 失败模式（频带错位泄漏）"分层标注的诊断 benchmark + 频域分解保真度量，系统刻画现有方法（含 GRPO 系）的保真崩坏模式，并以频域感知方法作为修复的 proof-of-concept。

## B.1 为什么这是顶会级

- **接住被埋没的真贡献**：评审发现 Idea 4 的"reward hacking 保真崩坏"现象刻画（被 FIRM 抢占框架）与 Idea 3 的"编辑深度分类"（被批查表）单独都不成文，但合并为**诊断学论文**后互为表里：分类学成为 benchmark 的标注体系，频域分析成为诊断工具；
- **benchmark + 诊断类论文**（TEdBench、EditVal、FIRM-Bench 的路数）在编辑领域有稳定录用记录，且"度量→诊断→修复"闭环比单点方法耐审稿；
- **评估器赛道竞争密度低**：EditHF-1M 已开源铺好对比基线，FIRM-Bench 关注 reward 评估而非保真失败模式——差异化清晰。

## B.2 三个贡献

1. **EditDepth-Bench**：约 1–2K 样本，按编辑深度 3 级（纹理/物体/结构）× 失败模式标注。失败模式用频域语言定义：纹理编辑的非编辑区高频泄漏、结构编辑的低频残余不足等；构造方式为现有强模型（Kontext、Qwen-Image-Edit、FireEdit 等）生成 + 人工筛选 + 受控扰动（对非编辑区施加分级位移/模糊/噪声，构造"语义相同、保真梯度变化"序列——吸收 Idea 4 的难例对巧思）。
2. **FreqFid 度量**：非编辑区的多尺度 DWT 子带能量一致性 + **平移鲁棒的相位一致性**（phase congruency，回应评审指出的"原始相位谱对位移过敏"硬伤）+ log-polar 相位变体；在 EditHF-1M 的 148K MOS 上验证与人感知保真的相关性（对比 LPIPS/DISTS/SSIM/CSD）——**相关性验证本身是独立贡献，且能提前证伪/救活频域信号路线**。
3. **诊断发现（论文的故事核心）**：用 benchmark + 度量系统评测 10+ 个主流方法，产出"失败模式地图"——例如预期发现：GRPO 后训练模型的语义分上升但高频泄漏加剧（reward hacking 的频域指纹）；免训练方法结构编辑不足但纹理编辑过度等。

## B.3 Proof-of-concept 修复（次要贡献）

- 频域感知引导（方案A 的简化版）或频域保真奖励（Idea 4 的奖励项，乘性组合参照 FIRM 的 CME）在 EditDepth-Bench 上显著优于基线——证明诊断的 actionable 价值。

## B.4 风险与对策

| 风险 | 对策 |
|---|---|
| benchmark 论文写作要求高（社区采纳叙事） | 强调与 FIRM-Bench/EditHF 的互补性；开源数据+代码+leaderboard |
| 相位一致性度量与人感知相关性差 | 这是实验问题而非设计问题——先做小规模相关性验证（2 周），失败则换多尺度 DWT 能量为主、相位为辅 |
| 标注成本高 | 编辑深度 3 分类用 GPT-4o 预标 + 人工校验（多人 kappa > 0.7）；失败模式可半自动（频域度量初筛 + 人工确认） |
| 与方案A 撞内容 | 明确分工：A 是理论+方法，B 是度量+诊断；B 引用 A 作为 POC 方法之一，互相抬轿 |

# 方案 C（保底）：抗 Hack 频域奖励（Idea 4 单点深挖）

*Goodhart-Proof Fidelity: Spectral Rewards with Hacking-Resistance Analysis for RL-Aligned Image Editing*

仅在 A/B 人手不足时执行。必须新增：① 对频域 reward 自身被 hack 的对抗分析（构造攻击 → 多尺度/随机频带采样的防 hack 机制）；② 跨模型验证（Qwen-Image-Edit + FLUX.1-Kontext 开源版或 Step1X-Edit）；③ 与 FIRM 乘性奖励、Edit-GRPO 保真项的头对头对比。创新天花板低于 A/B，预估 borderline。
